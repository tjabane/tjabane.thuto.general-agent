# File-Handling Tools

We need to build the following tools for handling files:

1. **`unzip`**
   - Extract the contents of ZIP archives.

2. **`list_directory`**
   - List the contents of a directory.

3. **`read_file`**
   - Read supported file contents, including:
     - Text files
     - CSV files
     - PDF files
     - Microsoft Excel files

4. **`read_media`**
   - Analyze image, audio, and PDF files using an LLM.
